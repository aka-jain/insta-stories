Checkout to feature/stories

# Stage Stories

## Installation

Install dependencies using npm:
npm i

## Development

Start the development server:
npm run dev

## Testing

Run end-to-end tests:
npm run test:e2e

## Design

1. Viewer provider to handle active user (opened story), handle story navigation
2. Common progress bar to load story
3. Every components are in modular state and very much isolated (connect using props or states)
4. Used transition and will-transform to acheive smooth transition animation
